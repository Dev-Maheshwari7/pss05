More than a duplicate file finder

DDAS determines whether an existing organizational dataset can satisfy a new request using identity, metadata, temporal, spatial and semantic signals.

🔎

Smart duplicate detection

Combines checksums, unique dataset IDs, source history, metadata and similarity signals.

🧠

Metadata intelligence

Period, region, variables, resolution, owner, location, permissions, lineage and integrity.

⚡

Instant reuse

Open the existing copy, mount it to a workspace or request owner access instead of downloading again.

📦

Repository visibility

Indexes central servers, lab repositories and user-owned research datasets in a common catalog.

🛰️

Scientific data aware

Designed to demonstrate climate, geospatial, satellite and ocean datasets with rich spatial-temporal metadata.

📊

Resource analytics

Quantifies prevented downloads, bandwidth saved, storage avoided, reuse rate and departmental impact.
